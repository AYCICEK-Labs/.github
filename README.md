# .github

The files GitHub reads for the whole **AYÇİÇEK Labs** organization.

| Path                               | What GitHub does with it                                                                          |
| ---------------------------------- | ------------------------------------------------------------------------------------------------- |
| `profile/README.md`                | Shows it on [github.com/AYCICEK-Labs](https://github.com/AYCICEK-Labs).                           |
| `.github/ISSUE_TEMPLATE/`          | Issue forms for every repository: bug report, feature request, task. Blank issues are turned off. |
| `.github/pull_request_template.md` | The description every new pull request starts with.                                               |

A repository with its own `.github/ISSUE_TEMPLATE/` folder replaces all of these forms, so it copies the ones it keeps.

Templates fill themselves in only on GitHub's web interface. From the command line, follow [`.agents/pull-requests.md`](https://github.com/AYCICEK-Labs/ai-rules/blob/main/.agents/pull-requests.md).
